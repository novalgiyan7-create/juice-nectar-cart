### 3. Design System & Visual Guidelines

- **Color Palette**:

  - Primary Green: `#22C55E` (Tailwind `green-500`) & `#16A34A` (`green-600`)

  - Accent Orange/Yellow: `#F97316` (`orange-500`) & `#EAB308` (`yellow-500`)

  - Background: `#F9FAFB` (`gray-50`)

  - Card Surface: `#FFFFFF` with soft drop shadows (`shadow-md`, `hover:shadow-xl`)

- **Typography**: Google Font `Inter` or `Poppins` imported via CDN/Tailwind.

- **Border Radius**: Rounded corners with `rounded-2xl` for cards/modals and `rounded-full` for badges & pill buttons.

- **Button Styles**: Solid primary buttons with smooth hover scaling (`transition-all duration-300 hover:scale-105 active:scale-95`).

- **Spacing**: Generous whitespace (`py-16 md:py-24` for sections, `gap-6` for grids).

### 4. React Component Structure

Organize code into modular components inside `src/components/`:

- `Navbar.jsx`: Navigation bar with cart drawer trigger & WhatsApp button.

- `Hero.jsx`: High-impact banner with CTA buttons and trust badges.

- `CategoryFilter.jsx`: Search input and category filter tabs.

- `ProductGrid.jsx` & `ProductCard.jsx`: Displays juice items with tags, pricing, and click handler.

- `CustomizerModal.jsx`: Interactive modal for ice, sweetness, and topping customization.

- `CartDrawer.jsx`: Slide-over cart with item quantity modifiers and checkout summary.

- `CheckoutModal.jsx` / `CheckoutForm.jsx`: Address input and simulated payment options.

- `OrderTracking.jsx`: Real-time order status progress tracker.

- `AdminPanel.jsx`: Tabbed dashboard for managing menu items and viewing incoming orders.

- `FAQ.jsx`: Accordion FAQ section.

- `Footer.jsx`: Footer with links and branding.
